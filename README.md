# More Than Irrational — Reading Notes

> A personal, research-oriented collection of paper notes on human–AI collaboration, computational rationality, cognitive modeling, and adaptive decision support. 🧠🤝🤖

## About this repository

This repository contains structured reading notes rather than publication-ready summaries. Each note preserves the paper's main argument, technical terminology, mathematical formulation, methods, experiments, evaluation evidence, limitations, and possible implications for human–AI systems.

## How the notes are organized

Most notes cover:

- research question and motivation
- key contribution and conceptual insight
- terminology in English and Chinese
- model assumptions and mathematical formulation
- algorithms and implementation logic
- figures, tables, and experimental evidence
- evaluation results and evidence boundaries
- limitations, open questions, and possible extensions
- implications for human–AI collaboration
